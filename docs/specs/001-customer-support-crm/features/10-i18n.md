# Feature Spec: Arabic/English i18n & RTL

**Requirement:** CRM-I18N-001
**Related task:** TASK-016

## Goal
The UI can switch between English and Arabic, with a correctly
mirrored right-to-left layout.

## Scope
- `react-i18next` with `en`/`ar` resource bundles covering nav, auth
  (login/register), dashboard, and the tickets screen.
- Language switcher (persisted in `localStorage`) flips
  `document.documentElement.dir`/`lang`.
- Logical CSS (`inset-inline-end`, flexbox) instead of hardcoded
  left/right so layout mirrors automatically under `dir="rtl"`.

Out of scope: translating every string in the app (customers/KB/reports
screens are not yet translated — only the core path required for
demo), server-persisted locale preference (User.locale exists in the
schema but isn't wired to a save endpoint — the switch is
frontend-only for now).

## Acceptance criteria
- [x] Switching to Arabic flips layout direction and translates the
      covered screens, including interpolated values (e.g. "Welcome,
      {{name}}").
- [x] Switching back to English restores the original layout.

## Implementation
- `frontend/src/i18n/` (config + `locales/en.json` / `ar.json`),
  `frontend/src/components/LanguageSwitcher.tsx`.

## Verification
`docs/verification.md`: "Arabic/RTL" row — PASS (Playwright, `dir`
flips ltr↔rtl, translated nav/auth/dashboard/tickets confirmed).
